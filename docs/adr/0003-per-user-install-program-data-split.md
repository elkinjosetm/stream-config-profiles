# Per-user install with a Program/Data folder split

v2's GUI installer needed a real file layout without requiring admin rights for the common path (install, edit paths, run the engine), so it splits into a PROGRAM folder (`manager.ps1` + `launch.vbs`) and a DATA folder (engine, `paths.txt`, `state.json`, `profiles\`). Elevation is reserved only for what genuinely needs it on Windows — host `.conf` editing, protected-location uninstall, and Logon watchdog registration.

## Consequences

- `-DataDir` is fixed and not user-changeable, since PROGRAM is fully regenerated by `Install-App` on every run — there's nowhere to persist a chosen DATA location for a later launch to recover.
