# Per-user install with a Program/Data folder split

v2's GUI installer needed a real file layout without requiring admin rights for the common path (install, edit paths, run the engine): `%LOCALAPPDATA%\Programs\stream-config-profiles\` (PROGRAM) holds `manager.ps1` and `launch.vbs`; `%LOCALAPPDATA%\stream-config-profiles\` (DATA) holds the engine (`sync-configs.ps1`, copied in from the manager's embedded payload), `paths.txt`, `state.json`, `sync.log`, and `profiles\`. The engine is deliberately co-located with its own data rather than split out, so its existing `$PSScriptRoot`-relative path resolution needs no changes, and Vibepollo's `global_prep_cmd` registration simply points at `<DATA>\sync-configs.ps1`. Elevation is reserved for exactly three categories that genuinely require it on Windows — editing the host's `.conf`/restarting its service, uninstall paths touching protected locations, and registering/unregistering the Logon-triggered watchdog task — never for the GUI process as a whole. `-DataDir` is fixed and not user-changeable in the wizard, since PROGRAM's contents are fully regenerated by `Install-App` on every run, so there's nowhere to persist a chosen DATA location for a later no-arg launch to recover it from.
